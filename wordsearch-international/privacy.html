Privacy Policy

Last updated: September 25, 2026 · MIT-licensed free and open-source word search

  • No ads
  • No AdMob / ad trackers
  • FOSS (MIT)
  • Self-hosted backend

WordSearch Winners collects as little data as possible. Anyone can self-host the backend. This policy describes the default PocketBase stack and optional self-hosted analytics. We do not sell personal data. We do not use AdMob or third-party ad trackers.

Support and privacy questions: open a GitHub Issue on yohann305/wordsearch-international. There is no separate company domain or privacy mailbox for this project.

1. What we collect

Data Purpose Stored where
Email + password hash Account, leaderboard identity Your PocketBase instance
Display name, game stats Profile, achievements, streaks PocketBase profiles
Daily scores Leaderboards PocketBase scores
Multiplayer room/claim events Live races PocketBase mp_*
Optional Umami page views Anonymous usage trends Your Umami instance, if enabled
Game Center player id, alias, scores, achievement progress iOS leaderboards and achievements Apple Game Center, on iOS only

If you play as a guest and never create an account, the server does not keep an email or password for you.

2. What we do not collect

  • Precise GPS location
  • Contacts, photos, microphone
  • Cross-app advertising IDs (no AdMob)
  • Payment card numbers (handled by Apple/Google if you use in-app purchases)

3. Local device data

The app may store on your device:

  • Auth session token (AsyncStorage)
  • Practice puzzle daily counter
  • Offline puzzle state

Clear app data or sign out to remove local tokens.

4. Analytics (optional, self-hosted)

If the operator enables Umami (self-hosted): no cookies are required for basic page analytics, there is no personal profiling, and the web build can show an opt-out banner.

If Umami is not deployed, no analytics run.

5. Error reporting (optional)

GlitchTip (self-hosted, Sentry-compatible) may receive crash stack traces without PII if the operator configures it.

6. Children’s privacy

The game is not directed at children under 13. We do not knowingly collect data from children.

7. Your rights (GDPR / CCPA)

You may:

  • Access your profile via the app when signed in
  • Delete your account — contact the server operator via GitHub Issues or use admin tools on a self-hosted PocketBase
  • Export scores — request from the server operator via GitHub Issues

Self-hosters may document an additional contact in EXPO_PUBLIC_PRIVACY_CONTACT. This project’s public contact is GitHub Issues only.

8. Data retention

  • Scores and achievements: retained while the account exists
  • Multiplayer rooms: deleted or archived after a game ends (operator policy)
  • Umami: default 90-day retention (configurable), if enabled

9. Open-source transparency

Full server schema and hooks live in server/pocketbase/ on GitHub. Host your own backend — no vendor lock-in.
